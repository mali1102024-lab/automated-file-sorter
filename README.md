# Automated File Sorter

## 📌 Project Overview
This Python project automatically organizes files into folders based on their file extensions.  
It uses the `os` and `shutil` libraries to move files into categorized directories such as CSV, images, and text files.

## ⚙️ Features
- Automatically creates folders if they don’t exist
- Moves files into the correct folder based on extension
- Supports `.csv`, `.png`, `.jpeg`, and `.txt` by default
- Easy to extend for other file types

## 🛠 Requirements
- Python 3.x
- Libraries: `os`, `shutil` (built-in, no installation required)
